# EMMA

**EMMA** (Extensible Multimodal Machine Assistant) is a production-quality AI platform designed to power:

- Desktop AI assistants
- AI glasses
- Robotics
- Autonomous systems
- Future intelligent devices

## Technology Stack

- Python 3.11
- AsyncIO
- Faster-Whisper
- OpenWakeWord
- Gemini API
- Ollama
- SQLite
- FAISS
- Edge-TTS
