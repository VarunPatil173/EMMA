# Module 02 - Configuration System

## Purpose

Centralized configuration system for EMMA.

## Responsibilities

- Load environment variables
- Validate configuration
- Provide default values
- Export a single `settings` object

## Used By

- Runtime
- Audio
- LLM
- TTS
- Memory
- Vision
